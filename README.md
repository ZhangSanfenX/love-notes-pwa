# ZYW♥CSX的恋爱手记 · PWA 1.7.2

可添加到 iPhone 主屏幕的离线恋爱手记。[打开手记](https://zhangsanfenx.github.io/love-notes-pwa/)。原生 Android 项目的网页版，不包含广告或分析脚本。未登录的记录只保存在本机；主动登录后，云日记通过独立同步服务保存到坚果云，不上传到 GitHub。



## 记录时间与表情名称修正

PWA 日记本、共享本及旧纪录新建自动读取设备系统时间，编辑保留原记录时间，不提供手动日期编辑。已有历史时间不重写。抱抱、贴贴、一起开心取消多余编号；成对主题仍保留1/2，不改变存储编号。

## 提醒与 iPhone 限制

GitHub Pages 托管页面，独立云服务发送共享本更新推送。纪念日定时提醒仍通过系统日历执行，未提供服务端定时推送。

日期及里程碑提醒可导出 `.ics` 日历文件，包含本地时间上午 9 点和提前 3 天的提醒；同日项目合并。每年重复的日期导出未来 10 年；2 月 29 日在平年按 2 月 28 日计算。

将 `.ics` 加入系统日历，开启日历通知，由系统执行提醒。不同 iOS 版本的本地 `.ics` 打开体验可能不同；若只能预览，可通过日历账户导入，或在电脑日历导入后同步到 iPhone。修改或删除 App 中的日期不会自动修改已导入的日历，需删除旧日历项目后重导。

PWA 无法创建原生 iPhone 桌面小组件。纪念卡可以保存 / 分享为图片；图中天数为导出时的快照。

## 数据与隐私

本站程序和插画公开，账号密码、会话令牌和网盘凭据不在源码中。纪念日、卡片、未登录日记及原有本地记录仍在各自设备保存；本次云同步范围仅为登录后的私人日记与共享本。GitHub 仍可能按其服务政策记录访问站点的网络信息。

云端通过 HTTPS 传输，服务端校验访问权限，坚果云中的正文及图片以 AES-256-GCM 加密保存。这不是端到端加密，也不能承诺零风险：Cloudflare 与同步服务管理员属于可信管理方，可以重设账号和维护服务。双方知道对方密码时，仍能作为对方登录；如需彼此保密，应各自修改密码。账号和密码按需求不区分大小写。

PWA 在浏览器 IndexedDB 保存登录会话、云端缓存及待上传内容，不是独立的加密保险箱。请保护手机，勿在同一 GitHub Pages 站点来源部署不可信脚本。退出会移除本机云端缓存；有未上传或冲突记录时需先处理。离线设备的旧缓存无法由服务端远程抹除。

坚果云应用密码保存在服务端，程序固定只访问 LoveNotesSync。应用密码本身可能具有其它网盘目录的 WebDAV 权限，程序的目录限制不等于网盘侧权限隔离；需要更强隔离时请使用独立坚果云账号。

系统清理网站数据、移除网页 App、更换手机或存储空间紧张可能造成数据丢失，请定期导出完整备份。备份包含个人照片和文字，请妥善保管。

导入上限为 80 MB 压缩包、110 MB 解压总量、25 MB 单项；图片选入上限 35 MB，普通日记照片缩小至最长 1600 像素。

## 本地运行与部署

无需 npm 构建，无线上 CDN 依赖。

```sh
python -m http.server 8767
node --test tests/core.test.js
```

打开 `http://localhost:8767`。Service Worker 需要 HTTPS，或本机 localhost。

GitHub Pages 发布 main 分支根目录。所有资源、manifest 与 Service Worker 都使用相对路径，兼容 `https://用户名.github.io/仓库名/`。程序更改后需修改 `sw.js` 中的缓存版本，再提交。新版会提示更新，不主动清空本机 IndexedDB。
